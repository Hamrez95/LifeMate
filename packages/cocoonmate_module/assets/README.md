# CocoonMate module assets

Cocoon-specific illustrations and icons belong in this directory so the reusable product module can be packaged by the standalone host today and a future LifeMate shell later.

Rules:
- use original LifeMate/CocoonMate artwork only;
- no competitor artwork or copied medical illustrations;
- do not encode PHI/person identifiers in filenames;
- keep critical status meaning accessible without color alone;
- large non-code clinical/content bundles should use the approved versioned content delivery path rather than being silently baked into widgets.
