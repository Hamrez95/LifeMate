# Living Camp visual references

These images were supplied as visual references for the LifeMate shell and Living Camp. They are kept in the repository for design and implementation work and are not bundled into the Flutter application as runtime assets.

- `living_camp_home_reference.jpg` — home screen and Living Camp composition.
- `living_camp_night_logo_reference.jpg` — night scene with the LifeMate mark and illuminated village.
- `living_camp_night_scene_reference.jpg` — night scene without the central mark; reference for day/night transitions and village lighting.
- `lifemate_logo_reference.jpg` — supplied LifeMate interlocking mark image. It is a JPEG reference, not a production transparent logo asset.
